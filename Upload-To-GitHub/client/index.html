Cloud Architecture & College Presentation

Architecture Overview

This web application operates on a 3-tier cloud-connected architecture:

  • Client Tier: HTML5, Vanilla CSS3, JavaScript SPA interacting with REST APIs.
  • Application Tier: Node.js & Express.js REST API handling CRUD, Mongoose ODM schemas, and security. Can be hosted locally or deployed to AWS EC2.
  • Database Tier: MongoDB Atlas cloud cluster hosting the student_management_db database and students collection.

Database vs Relational DB (Viva Point)

Unlike Amazon RDS or MySQL which use tabular rows and rigid schemas, MongoDB Atlas is a document database storing flexible, JSON-like BSON documents. Mongoose enforces application-level validation, indexes, and type-safety.
